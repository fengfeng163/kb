准备 **ServiceNow CSA (Certified System Administrator，系统管理员)** 证书考试，是进入 ServiceNow 生态的黄金第一步。

值得高度注意的是，**ServiceNow 官方对认证考试进行了重大重构**：过去广为人知的“Kryterion / Webassessor”考试系统和“购买 Voucher（券）”的模式已经被彻底废除。现在所有的考试都全面迁移到了 **ServiceNow University 平台，并改由 Pearson VUE 进行承考（支持线上和线下考点）**。

为了帮你最高效、甚至最低成本地拿下这张证书，以下是为你整理的**备考一条龙通关指南**：

---

### 第一步：解锁“考试资格”（免费 vs 标价 $300）

根据最新的官方规则，你不能直接买门票去考试，必须先在 **Now Learning** 官方平台上**解锁考试资格**。有两种解锁方式：

1. **免费的自学路线（On-Demand Course）—— 最推荐：**
    
    - 去 Now Learning 平台搜索并完成 **Welcome to ServiceNow** 和 **ServiceNow Administration Fundamentals**（管理员基础课程）。
        
    - **成本：** 课程本身是 **$0 免费**的。当你百分之百刷完这门课（包括里面的 Simulator 实验环境）后，你的账号会自动解锁 CSA 考试资格。
        
    - **考试门票费：** 资格解锁后，你需要单独在系统里支付 **$300 美元**的考试费。
        
    - _注：如果你的公司是 ServiceNow 的官方合作伙伴（Partner），部分公司在员工刷完免费课程后，会直接报销或提供免费的考试机会。_
        
2. **付费的讲师带教路线（Instructor-Led Training）：**
    
    - 报名参加官方组织的多天真人讲师直播/面授课。
        
    - **成本：** 极其昂贵（约 $2,700 美元），但这个费用里**已经包含了一次免费的考试机会**。一般只有公司统一出钱培训才会选这个。
        

---

### 第二步：吃透“官方教材”（考试出题的唯一依据）

ServiceNow 官方出题非常死板，**95% 以上的题目都出自你上课时的那本电子教材（Student Guide）或官方 Docs 文档**。

在刷官方的 _ServiceNow Administration Fundamentals_ 课程时，重点攻克以下五个核心板块：

1. **用户界面与导航 (User Interface & Navigation)：** 导航栏的使用、Next Experience 界面、如何创建和分享 Dashboards（仪表盘）、列表（Lists）和表单（Forms）的配置。
    
2. **数据架构 (Collaboration & Data)：** **这是重中之重！** 必须弄懂数据表（Tables）的继承关系（如 Task 表与 Incident 表）、什么是本地应用域（Scoped Application）、以及 **CMDB（配置管理数据库）** 的基本概念（CIs、类和关联性）。
    
3. **业务自动化 (Service Automation)：** 熟练掌握 Flow Designer（工作流设计器）、Service Catalog（服务目录项的配置）以及 Knowledge Management（知识库）。
    
4. **数据库管理 (Database Administration)：** 弄清数据的导入导出（Import Sets、Transform Maps）、用户权限控制（Users, Groups, Roles，尤其是 **ACL 访问控制列表**的匹配机制）。
    
5. **配套应用与开发 (Supporting Applications)：** UI Policies（UI 策略）、Client Scripts（客户端脚本）、Business Rules（业务规则）的概念和区别。_（CSA 考得不深，但你要知道它们分别在什么场景下用，开发 CAD 时才会深挖）_。
    

---

### 第三步：大杀器 —— 刷模拟题（Exam Dumps）

当你把官方课程刷完（进度达到 100%），并且对上面的基础概念有印象后，**请立刻开始刷题**。

- **去哪里找题？** 在 **Udemy** 网站上搜索 “_ServiceNow CSA Practice Exams 2026_”（记得认准最新年份和当前大版本，如 Xanadu 或最新的版本）。花几十块钱买几套评价最高的模拟题。
    
- **怎么刷？** 模拟题通常有 4-6 套。
    
    - **第一遍：** 严格按照时间闭卷做，把错题全部抠出来。
        
    - **查漏补缺：** 错题不要只看模拟题的答案解释，**一定要登录你申请的免费个人开发实例（PDI）里去亲自点一遍、配置一遍**，或者去官方 Docs 文档里搜原话。
        
    - **第二遍：** 刷到每套模拟题的正确率能达到 **90% 以上**，并且你看到题目能瞬间反应出考点在哪，就可以去报名了。
        

---

### 第四步：报名与上战场（新规避坑）

当你觉得准备好了，直接在 ServiceNow University 平台里预约 Pearson VUE 承办的考试。

**⚠️ 2026年最新规则极其重要，一定要避坑：**

1. **90天有效期限制：** 只要你在系统里付了钱（或激活了考试资格），你**必须在 90 天内完成考试**。如果超过 90 天你没去考，这一笔考试费将直接作废，不予退款。
    
2. **改签规则：** 考试预约后**无法取消退款**，但在规定的考试时间前，你可以免费改签（Reschedule）日期，只要不超出那 90 天的整体窗口即可。
    
3. **考试形式：** * **线下考点（Onsite）：** 推荐。直接去 Pearson VUE 的线下大楼，带好身份证件，比较省心。
    
    - **线上监考（Online）：** 需要在一个完全封闭隐秘的房间，电脑安装专用的监考浏览器，摄像头全程盯着你，对网络稳定性和环境要求极高。
        
4. **考试题型：** 总共 **60 道题**（单选题和多选题），考试时间 **90 分钟**。多选题会明确告诉你“选择2个正确答案”或“选择3个”，没有模糊地带。通过分数线通常在 **70% 左右**（官方不公布具体分数，考完只告诉你 Pass 或 Fail）。
