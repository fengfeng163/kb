## ユーザーストーリー 

Infinity HHD の IT プロダクトオーナーとして、Infinity (HHD) サービスオファリングに重大な (P1) インシデントが作成されたときに**通知を受ける**必要があります。  

また、Training Technology Support グループのメンバーにも、重大な (P1) インシデントについての**メールを受信**させたいと考えています。

## メール通知
![[Pasted image 20260626080427.png]]
通知は、以下の方法により、関連するイベントが発生したことをユーザーにアラートで知らせるツールです。  
- 電子メール  
- SMS  
- 会議への招待  
 
メール通知を使用すると、インシデントの更新や変更要求など、システムにおける特定のアクティビティについて、選択したユーザーに電子メールまたは SMS 通知を送信できます。新しい通知レコードにアクセスするには、[All] > [System Notification] > [Email] > [Notifications] を選択します。  

ヒント：インスタンスで通知を表示するには、[All] > [System Mailboxes] > [Outbound] > [Outbox] の順に移動します。作成日を右クリックして、[Preview Email] を選択します。

## 通知の作成

![[Pasted image 20260626080649.png]]
![[Pasted image 20260626080703.png]]

通知を作成するときに、管理者は次のことを指定できます。
• 通知の送信タイミング
• 通知の受信者
• 通知の内容

[When to send] ドロップダウンのオプションは次のとおりです。
• Record inserted or updated
• Event is fired
• Triggered
• Script (詳細ビューモードの場合)。

通知は、特定のユーザーやグループに送信できます。User [sys_user] テーブルで非アクティブなレコードを持つユーザーを通知の宛先に入れた場合、システムではそのユーザーに通知を送信しません。

ヒント : 任意の通知の受信者リストを 1,000 ユーザーに制限する場合を考えます。デフォルトでは、通知に 100 人を超える受信者が含まれている場合、システムはそれぞれ最大 100 人の受信者を含む複数の通知メッセージを作成します。受信者の制限を変更するには、システムプロパティ glide.email.smtp.max_recipients を設定します。

メールテンプレートを使用している場合、異なる (新しい) 件名とメッセージでオーバーライドされないかぎり、そのテンプレートの件名とメッセージが使用されます。

## メールレイアウトとテンプレートを使用した通知
![[Pasted image 20260626080833.png]]
メールレイアウトを作成して、1 つまたは複数のメールテンプレートの本文に表示する HTML コンテンツを指定します。デフォルトで、システムに複数のサンプルレイアウトが含まれており、管理者はこれらを使用して独自のレイアウトを作成できます。アドミニストレーターはインライン HTML エディターを使用するか、手動で HTML コードを入力してメールレイアウトを作成できます。  

1. [All] > [System Policy] > [Email] > [Layouts] に移動します。  
2. [New] をクリックします。  
3. フォームに入力します。  
4. [Submit] をクリックします。  
 
システムでは、メールレイアウト [sys_email_layout] テーブルにメールレイアウトレコードが保存されています。  

システムでメールレイアウトレコードが作成されます。  

メールテンプレート :  
1. [System Notification] > [Email] > [Templates] に移動します。  
2. 既存のメールテンプレートのリストが表示されます。  
3. メールレイアウトに適用するメールテンプレートを選択します。  
4. メールレイアウトで、メールメッセージ本文のフォーマットに使用するメールレイアウトを選択します。  
5. [Update] をクリックします。  
 
メールテンプレートでは、選択したメールレイアウトを使用してメールメッセージ本文がフォーマットされます。  

詳細については、ServiceNow 製品ドキュメントを参照してください :  
『メールレイアウトを作成する』  
『メールテンプレートを作成する』

## サブスクリプション
![[Pasted image 20260626081142.png]]
設定の [Notifications] ページで、ユーザーは通知チャネル (通知の受信方法) を指定したり、システム通知のサブスクリプションを管理したりできます。

SMS (Short Messaging Service) は、モバイルデバイスに短いテキストメッセージを送信するために使用される標準的なプロトコルです。ほとんどの携帯電話は、メール通知のような高度なメッセージングをサポートしていない場合でも、SMS をサポートしています。

SMS デバイスへの通知は、重大なイベントにすぐに対処する必要があり、メール通知へのアクセスと確認を待てない場合、特に役立ちます。

2 つのフィールド ([Force Delivery] と [Mandatory]) を使用して、特定の通知を登録解除できないようにすることができます。
