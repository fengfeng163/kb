# モジュール 5 : セルフサービスの構成
## モジュールの目標
- ポータル、ナレッジ、サービスカタログ、仮想エージェントなどのセルフサービスオファリングをどこに構成するかを理解する  
- Word ドキュメントをインポートしてナレッジベース記事を作成する  
- 記事の公開を承認する  
- ナレッジベースのユーザー基準を定義、適用、およびテストする  
- カタログビルダーを使用してサービスカタログアイテムを作成する  
- Workflow Studio を利用して、既存のフローを活用したり新しいフローを作成したりする  
## ラボ 5.1.1 :
ナレッジベースの管理および記事の作成  5.2.1 : カタログアイテムの作成  5.3.1 : Workflow Studio のフローの作成

## ベースラインのセルフサービスオプションの概要
- ポータルを使用すると情報に簡単にアクセスできます。 
- 複数のセルフサービスポータルから選択し利用することができます (例 : 従業員サービス、IT、HR)。 
- ベースラインのポータルをそのまま使用できますが、顧客のニーズに合わせて変更することもできます。 
- UI Builder を使用して、CSM 構成可能なワークスペース、App Engine Studio で生成されたワークスペースとポータル、またはカスタム Web エクスペリエンスのページを作成できます。 
- Service Portal Designer を使用して、ベースラインポータルをカスタマイズできます。

次のポータルをプラットフォームベースラインで使用できます。
**Employee Center (/esc)** : Employee Center によって、従業員が必要とするすべての情報、サービス、ヘルプを得られる 1 つの統合ポータルを提供できます。従業員は、To-Do の完了、すべての要求の確認、ナレッジベースやカタログの閲覧、ライブエージェントとのチャットなどを行うことができます。

**Service Portal (/sp)** : この Service Portal の例では、ユーザーがナレッジベースの検索、複数のカタログの閲覧、要求を行うことができます。インシデントの作成と表示、承認の確認、[System Status] ページの表示も可能です。  

**Knowledge Portal (/kb)** : ナレッジベースや記事の表示、情報の検索、検索結果のソートとフィルタリング、フィードバックの提供を行えます。Knowledge Management : Service Portal プラグイン (com.snc.knowledge_serviceportal) を有効化する必要があります。  

**Change Advisory Board (CAB) Workbench (/cab)** : Change Advisory Board (CAB) Workbench では、CAB マネージャーが CAB 会議のスケジュール設定、計画、管理を行えます。CAB 会議は、通常、変更要求を確認および承認したり、最近実行された変更を確認したりすることを目的としています。

**Security Center** : インスタンスのセキュリティ制御に関するコンプライアンスレベルの監視、セキュリティイベントモニタリングの測定基準の表示、インスタンスセキュリティ設定の構成と保守のすべてを Security Center 内で実施できます。Security Center は複数の主要なセキュリティコンポーネントを 1 つの制御コンソールに統合し、インスタンスベースのセキュリティイベントの検出、保護、対応を支援します。
