## ユーザーストーリー
**IT プロダクトオーナー**として、Infinity HHD サービスオファリングを**モニタリング**できる**ダッシュボード**が必要です。その他にも、HHD インシデントレコードを、「パイロット (試験使用) とそれ以外」「ファームウェアとそれ以外」で比較できるような可視化(Data Visualization)や、オープン中の P1 HHD インシデントのチャートも必要です。

## Platform Analytics
![[Pasted image 20260625204646.png]]
Platform Analytics アプリケーションを使用して、プロセスを最適化し、生産性を向上することができます。これらのアプリケーションには、Visualization Designer、Performance Analytics、User Experience Analytics、およびProcess Mining が含まれます。データは、コアUIまたはプラットフォームアナリティクスエクスペリエンスを通じて表示することができます。  可視化は、棒グラフ、円グラフ、目盛り、リスト、ピボットテーブル、ドーナツなど、多くの方法で視覚的に表現することができます。

可視化は手動で実行することも、自動実行をスケジュールすることもできます。重要業績評価指標 (KPI : Key Performance Indicator) レポートを含め、Incident Management や Service Catalog 要求などのアプリケーションや機能に関連する各種の条件が事前に定義されています。  

ServiceNow の可視化はインタラクティブに使用できます。アクセス権があるユーザーは、ドリルダウンして、ベースとなるデータを表示および操作できます。  

事前に定義されている条件がニーズに合わない場合は、[All] > [Platform Analytics] > [Library] > [Data Visualizations] を選択して独自のチャートを作成できます。また、任意のリスト内にあるほとんどの列コンテキストメニューでは、それをクリックするだけで、そのリスト内のデータからチャートを直接生成できます。  

ServiceNow の Platform Analytics のユースケースを確認してください： 
- 管理者は、夜間に発生したすべての P1 インシデントのチャートを自動的に作成し、担当部門に配信する必要があります。   
- サードパーティベンダー管理者は、サービスプロバイダのサービスレベル遵守状況を四半期ごとに確認する必要があります。  
- HR 部門ではは、オープンエンロールメント期間中の担当者ごとの平均給付金ケースの負荷を測定するために、可視化を活用できます。  
- エージェントは、四半期レビューに備え、前四半期のケース管理実績をレポートする必要があります。 
 
詳細については、[All] > [Platform Analytics] > [Analytics Center] の順に選択してください。

このコース外で、Xanadu 以前のインスタンスを使用している場合は、プラットフォームアナリティクスデータを移行する必要があります。詳細については、以下の製品ドキュメントを参照してください :   
[Jumpstart Your Migration of Platform Analytics  ](https://www.servicenow.com/docs/r/OLEAh14mAEPe8fUlW2F9wQ/S33Z4Mddh6t6GJRVeNbJ2w)
[Platform Analytics Migration](https://docs.servicenow.com/csh?topicname=data-migration.html&version=latest)

## 可視化タイプ
![[Pasted image 20260625205334.png]]

その他の可視化タイプには、スピードメーター、目盛り、単一スコアグラフ、円グラフ、半ドーナツグラフ、バブルチャート、マルチレベルピボットテーブル、線グラフ、縦棒グラフ、面グラフ、折れ線グラフ、棒グラフ、ヒストグラム、水平棒グラフ、リスト、じょうごグラフ、カレンダー、ピラミッドグラフ、ボックスチャート、傾向図、管理図、Trendbox グラフ、マップ、ピボットテーブル、およびテキスト分析などがあります。  

チャートを新しく作成することもできますが、フィルタリングしたリストや既存の可視化から始めた方が通常は簡単です。既存のチャートから開始する場合、チャート構成の選択肢が表示されます。所定のオプションを変更して、ニーズに合わせた可視化を構成することができます。ベースとなる可視化を複製して編集することをお勧めします。  

既存の可視化を編集して使用するメリット :  
- 基本的な情報がすでに含まれている可視化から始めて、一部変更することで 必要な結果が得られます。  
- 既存のチャートを参照すると、どのテーブルが自分の作業に適しているかを知ることができます。  
- 様々な可視化タイプの用途を学ぶことができます。  
- 重要業績評価指標 (KPI) レポートを使用して、ITIL のベストプラクティスを活用できます。

## データ可視化(Data Visualization)の制御
![[Pasted image 20260626074911.png]]

[All] > [Platform Analytics] > [Library] > [Data Visualizations] の順に選択すると、可視化のライブラリがあります。このライブラリは、独自の可視化を作成する際に使用したり、実行したりできます。これらの可視化の多くはプラットフォームに含まれていたもので、その他は、レポート管理者が会社用に作成したものです。可視化とダッシュボードの作成と配布の方法について、詳細は [All] > [Platform Analytics] > [Analytics Center] で確認できます。

## Visualization Designer
![[Pasted image 20260626075000.png]]
ServiceNow Visualization Designer を使用して、以下のことができます。 
- レポートの可視化と有効な可視化タイプを利用する 
- マルチレベルフィルター、フィルター演算子、およびソート順を使用して、可視化した内容を絞り込む 
- 可視化を表示、作成、編集、およびスケジュールする 
- レポートのロールを使用する 
- 関連テーブル (ドット連結およびデータベースビュー) を使用する 
 
Visualization Designer の各セクションには、さまざまな構成オプションがあります。次のオプションを設定できます。  
- Data : 使用するデータのソースを選択します。データソース (可視化の作成に使用する事前定義されたデータセット) または ServiceNow のテーブルを選択できます。 
- Type : タイプを選択することによって、チャートの表示方法を選択します。20 種類以上のタイプから選択できます。 
- Group by and Sorting : 特定のフィールドごとのデータのグループ化やデータに対する計算などを実行します。 
- Presentation : 色分けやタイトルなどの可視化の外観や、凡例を調整します。 
 
システムテーブルは、デフォルトではレポートモジュールでの使用が制限されています。それらのテーブルには、syslog、syslog_transaction、sys_attachment、および sys_email が含まれますが、これらに限定されません。  

システムテーブルのレポート作成方法の説明を含めた詳細については、ServiceNow製品ドキュメント『システムテーブルのレポート』にアクセスしてください。

## Visualization Designer のアクションとオプション
![[Pasted image 20260626075437.png]]
Visualization Designer のアクションには、ダッシュボードへの追加、保存、その他のオプションメニューが含まれています。可視化の一部をカスタマイズするには、構成パネルを選択または選択解除します。[Details] サイドパネルを選択すると、可視化の名前、説明、リクエスト、所有者、グループを設定できるほか、可視化の作成日時や最終更新日を確認できます。

## フィルターと事前定義の条件
![[Pasted image 20260626075531.png]]

事前定義された条件を追加したり、独自の条件を作成します。選択したテーブルによっては、事前に定義された条件がない場合もありますが、条件を作成してフィルターを実行するオプションは常に用意されています。結果はテーブルによって異なります。完了したら、[Add this source] を選択して可視化のスタイル設定を続行します。

## ダッシュボード
![[Pasted image 20260626075622.png]]
ダッシュボードでは、次のことが可能です。  
- Platform Analytics と可視化の情報をワークスペースと従来のダッシュボードの両方で共有できます。 
- Platform Analytics および他のウィジェットをダッシュボードから直接作成および編集できます。 
- [Add Widgets] ペインを使用して、ウィジェットをすばやく見つけてプレビューし、ダッシュボードに追加できます。 
- 統合型の共有ペインから他のユーザーとダッシュボードを簡単に共有できます。 
- クイックレイアウトを使用して、事前定義されたレイアウトにウィジェットをスナップし、必要に応じてレイアウトを調整できます。 
- 頻繁に使用する情報に簡単にアクセスできるように、ダッシュボードをホームページに設定できます。

## ダッシュボードに可視化(Data Visualization)を追加する
![[Pasted image 20260626075802.png]]

データの可視化およびダッシュボードを利用するには、[All] > [Platform Analytics] > [Analytics Center] の順に選択します。[Create new dashboard] または [Create new visualization] を選択して利用することも可能です。  

ダッシュボードに可視化を追加するには、ダッシュボードを作成し、要素として可視化を追加します。また、新しいダッシュボードまたは既存のダッシュボードに可視化を追加する場合は、最初に可視化を保存し、[Add to Dashboard] を選択します。Visualization Designer での手順は以下のとおりです。
1. [Add to Dashboard] オプションを選択し、[ Add to new dashboard] または [ Add to existing dashboard] を選択します。 
2. ダッシュボードの名前が、選択したダッシュボード、または作成したダッシュボードのものであることを確認し、[Add to Dashboard] を選択します。 
3. ダッシュボードに可視化が表示されます。

## ワンタイムレポートと Platform Analytics の比較
![[Pasted image 20260626075947.png]]


Platform Analytics (PA) では、改善が必要な領域を特定するために、ウィジェットを組み込んだダッシュボードを作成してデータを経時的に視覚化することができます。PA で、すぐに使える ServiceNow の機能やコンテンツを使用して測定やレポートのシナリオに対応することにより、ユーザーは事業達成目標にとって重要な測定基準を特定できるようになります。  

プラットフォームで可視化を実行する場合とは異なり、分析ソリューションの開発と使用が継続的かつ反復的に行われるので、ユーザーはそのプロセスを経時的に改善できます。業績指標を確認し、測定基準を監視し、組織の意思決定を改善します。  

Platform Analytics のアーキテクチャは次のとおりです。  
- ウィジェット - インジケーターやブレークダウンが保存されたビュー 
- テーブル : インジケーターソース - スコアを計算 
- データコレクター - データスナップショットを定期的に作成するジョブ 
- ダッシュボード - ウィジェットを任意に配置 

PA の基本的な概要については、Now Learning の Platform Analytics Essentials を受講するか、ServiceNow 製品ドキュメント『Platform Analytics』を確認してください。  

Platform Analytics では、定期的に継続的なスナップショットを取り込むことによって時系列的な傾向を正確に生成します。ここに示されているように、Reporting は「現在の状況」を示しますが、Platform Analytics は経時的に何が起こっているのかを示します。  

スナップショットから傾向を割り出すことに加えて、Platform Analytics では次のことが可能です。  
- 目標に対するパフォーマンスの追跡 
- しきい値を満たしたときのアラート 
- 将来のパフォーマンス予測 
- 異なる時点でのパフォーマンスの比較
