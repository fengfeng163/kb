## ユーザーストーリー
管理者として、プラットフォームのプラグインと機能を利用して、会社のインスタンス全体で Now Assist と連携できます。

## Predictive Intelligence
![[Pasted image 20260626081336.png]]
admin または ml_admin ロールを持つユーザーは、Predictive Intelligence のセットアップを開始できます。  

Predictive Intelligence の有効化と定義が完了すると、自分のデータに合わせて適切にパーソナライズされた機械学習が実現されます。  

たとえば、インシデントを作成すると、ServiceNow は、レコードの [Short Description] フィールドに基づいて適切なカテゴリ、優先度、アサイン先グループを自動的にアサインします。要求者が最適なカテゴリを選択するためにいくつものリストをスクロールする必要はなくなります。また、作成したインシデントに適切な処理とふさわしい SLA が適用されるため、全体的なサービスレベル満足度が向上します。  

この機能を使用するには、複数のプラグインが必要です。  

詳細については、ServiceNow 製品ドキュメント『Install Predictive Intelligence』を参照してください。

## Now Assist
![[Pasted image 20260626081526.png]]

Now Assist Admin Console では、生成 AI を活用した機能を ServiceNow プラットフォーム全体で利用・管理することができます。ここで IT や顧客、従業員のペルソナに対して製品プラグインをインストールすることも可能です。このコンソールを使用して、コンソールが提供するすべての機能と設定について学習できます。開発者インスタンスに今すぐ登録して、Now Assist Admin Console を試してみてください。

ServiceNow 製品ドキュメントで『Now Assist』を参照してください。

## サポート対象ワークスペースで Sidebar の使用

Sidebar を使用すると、エージェントは、ワークスペースのタスクベースまたはインタラクションベースのレコードに基づいて他のユーザーとリアルタイムでコラボレーションできます。
![[Pasted image 20260626081616.png]]

Sidebar ディスカッションは、情報や知識の交換を促進して、より迅速な問題解決や質の高い成果の実現を支援します。
1. Sidebar ディスカッション : Sidebar ディスカッションダイアログが表示されます。
2. ピン : 画面の端にメニューを永続的にピン留めできます。
3. [All]、[Unread]、[Favorites] : すべてのディスカッション、未読のディスカッション、お気に入りとしてマークしたディスカッションのみを表示するかどうかを選択します。

Sidebar は次のワークスペースでサポートされています。
• CSM Configurable Workspace
• CSM Manager Workspace
• HR Agent Workspace
• ITSM Manager Workspace
• Vendor Management Workspace

## ドッキングチャットウィンドウ (履行者)
![[Pasted image 20260626081704.png]]
ドッキングチャットウィンドウの機能は次のとおりです。
1. お気に入り : Sidebar ディスカッションをお気に入りとしてマークします。お気に入りとしてマークされたディスカッションは、[Favorites] タブに表示されます。
2. 情報 : [About] サブメニュー、[Participants] サブメニュー、[Leave Discussion] ボタンを含むディスカッション情報パネルを開きます。
3. 折りたたみ : ディスカッションを折りたたんで、画面下部にタブとしてのみ表示します。
4. 終了 : ウィンドウを閉じます。

ユーザーのアバターとプレゼンス : ユーザーのアバターとプレゼンス (オンラインステータス) を表示します。ドットは、ユーザーがプラットフォームにログインしているかどうかのプレゼンスを示します。
• 緑のドット - ログインしています。
• ドットなし - ログインしていません。
• オレンジのドット - 最近ログアウトしました。

A. ベースシステムまたはカスタムクイックアクションにアクセスします。
B. ディスカッションに絵文字を追加できるように、絵文字メニューを表示します。
C. ディスカッション内の他のユーザーと共有できるように、現在のディスカッションに添付ファイルを追加します。
D. メッセージを送信します。

最小化されたドッキングウィンドウにカーソルを合わせると、レコード番号とチャットタイトルが表示され、コンテンツの識別に役立ちます。オーバーフローメニューを使用すると、エージェントは画面上に表示しきれないウィンドウにアクセスできます。オーバーフローメニューのウィンドウの最大数は 25 です。この数は設定可能です。

## Sidebar の Activity Stream
![[Pasted image 20260626081805.png]]
Sidebar ディスカッションを作成すると、対応する Sidebar ディスカッションタイルが Activity Stream に自動的に追加されます。タスクベースレコードへのアクセス権を持つユーザーは、Activity Stream からディスカッションにアクセスすることもできます。Sidebar 内にもコントロールがあり、Sidebar の投稿メッセージとしてディスカッションから Activity Stream にメッセージを投稿できます。Sidebar ディスカッションからのメッセージは、必要に応じて追加および削除できる編集可能エントリとして Activity Stream に投稿できます。

顧客と履行者以外のロールは、作業メモと同様に、レコードにも会話タイルにもアクセスできません。

Activity Stream にメッセージを投稿するには、Sidebar ディスカッションパネルでメッセージを選択して Activity Stream に投稿します。Sidebar ディスカッションからプライマリレコードの Activity Stream にメッセージを投稿すると、最も重要な情報がレコードに直接関連付けられます。
