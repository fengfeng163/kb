Once a Script Include is named, a Script Editor Macro is automatically inserted in the Script field and the Name is propagated throughout the script. If you change the Name of the Script Include, the script automatically updates to reflect the change.

>**Tip from the Field**: Script Includes/Class names often include a table name (for example, IncidentUtils, ChangeUtilsSNC, KBUtils) to group/manage functions. In the case of smaller applications with minimal tables, you could instead include the application name in the Script Includes/Class name (for example, TravelMgmtUtils).
