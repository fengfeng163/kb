## The Syntax Editor: syntax coloring
Applies color coding to scripts for readability.
![[Pasted image 20260719222247.png]]
Syntax coloring improves the readability of a script.  

When writing scripts, you cannot choose a JavaScript reserved word as a variable name.  

JavaScript commands tell the platform what to do.  

Comments help you, future you, coworkers, sock monkeys, and the next administrator understand the code. Comments do not affect the code’s execution.  

Bold, italicized text indicates that the item has a Context menu associated with it. Right-clicking the bold text opens the Context menu.
