### GlideRecordSecure
1. Class inherited from GlideRecord
2. Performs the same functions as GlideRecord AND enforces ACL rules.

![[Pasted image 20260818214728.png]]

GlideRecord can handle a variety of data manipulation tasks, but can it restrict data to certain users? Yes, the GlideSystem methods discussed in Module 5, like hasRole(), canRead() and canWrite() used in conjunction with GlideRecord restricts data to users that have the correct roles. However, you must include the appropriate conditional checks every time data is queried. This strategy is NOT considered best practice.
